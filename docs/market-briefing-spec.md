# 장 마감 브리핑 기능 명세서

작성일: 2026-11-16 · 상태: 논의용 초안

## 1. 목적과 범위

한국 주식시장 마감 후 대시보드에 이미 있는 자료를 모아 일간 또는 주간 브리핑을 확인하고 PDF로 보관한다. 개인 리서치에 필요한 시장 변화와 자료의 기준을 빠르게 파악하는 것이 목적이다. 이 문서의 화면 구성과 기본값은 제안이며 구현 완료를 뜻하지 않는다.

수동 생성 외에 이 PC에서 자동 생성한다. 매일 16:00~23:30 KST 30분 간격으로 거래일 여부와 자료를 확인해 일간을, 해당 주 마지막 거래일에는 주간도 생성한다. 필수 지수 미확보 시 재시도하고, 선택 자료는 20:00까지 기다린 뒤 결측을 명시해 생성한다. 자동 PDF와 스냅샷은 이 PC에 보관하며 자동 수집을 실행하지 않는다. 알림, 뉴스 수집, 종목 추천과 AI 해설은 제외한다.

## 2. 꼭 필요한 화면

별도 화면을 여러 개 만들기보다 사이드바의 **장 마감 브리핑** 한 곳에서 목록과 생성·검토를 처리한다. PDF는 별도 산출물이다.

### 화면 A. 브리핑 목록 및 생성

```text
장 마감 브리핑
일간 | 주간                         [+ 새 브리핑]

유형   기준일 / 대상 주간       상태        생성 시각       동작
일간   2026-11-16              생성 완료   17:10 KST      보기 · PDF
주간   2026-11-09 ~ 11-13      일부 결측   17:20 KST      보기 · PDF
```

- 일간·주간 필터, 최신순 목록, 빈 상태와 생성 진입 버튼을 제공한다.
- 목록에는 실제 기준 거래일 또는 대상 주간, 자료 상태, 생성 시각을 표시한다. 자료 상태와 PDF 생성 성공 여부는 별도로 관리한다.
- 유형과 날짜를 선택한다. 날짜 기본값은 오늘이며 일간은 실제 완료 거래일로 해석한다. 주간은 선택일이 속한 주의 마지막 거래일 마감 후에 확인할 수 있다. 미래 날짜는 선택할 수 없다.
- 선택 후 실제 거래일, 각 자료의 준비 상태와 기준일을 보여 주고 **검토 화면으로 이동**한다. 주말·휴장일의 일간 선택은 직전 완료 거래일로 해석하고 선택일과 실제 기준일을 함께 표시한다. 거래일을 확정할 수 없으면 생성을 막고 이유를 표시한다.
- 목록에서 저장된 스냅샷을 연 후 PDF로 저장할 수 있다. 기존 자료가 없으면 빈 상태에서 새 브리핑을 만들 수 있다.

### 화면 B. 자료 확인 및 브리핑 검토

```text
일간 브리핑 · 2026-11-16                 KRX 정규장 15:30 KST
자료 확인: 필수 2/2 준비 · 선택 1개 결측
지수       준비  기준일 11/16   수집 16:08
섹터       준비  기준일 11/16   수집 16:15
투자자 수급 결측  해당 기준일 자료 없음

[시장 요약] [섹터] [수급]     ← 실제 보고서 순서대로 미리보기
결측: 투자자 수급을 불러오지 못했습니다.

[뒤로]                              [브리핑 저장 및 PDF 생성]
```

- 자료별 준비·결측·기준일 불일치·수집 실패를 표시한다. 수집 시각은 가격 기준 시각과 구분한다. 자료가 없거나 확인할 수 없는 시각은 임의로 채우지 않는다.
- 필수 자료는 해당 기준일 코스피·코스닥 지수 종가와 비교 기준 거래일의 같은 기준 종가다. 하나라도 없으면 PDF 생성을 차단하고 누락 항목을 표시한다. 선택 자료의 결측은 표시한 상태로 생성할 수 있다.
- 보고서에 들어갈 표·문구와 결측 표시를 인쇄와 같은 순서로 미리 보여 준다.
- 자료 확인 중 진행 상태를 표시하고 중복 실행을 막는다. 실패하면 원인과 재시도를 제공한다. 브라우저 인쇄 창에서 PDF를 별도로 저장하며 저장 성공 여부를 앱에서 확인하지 않는다.
- 저장된 브리핑을 다시 열면 생성 당시 스냅샷을 보여 준다. 새 자료를 반영하려면 새 스냅샷을 저장하고 기존 결과는 유지한다.

## 3. 보고서 내용과 계산

### 일간

1. 표지/요약: 실제 기준 거래일, KRX 정규장 15:30 KST, 생성 시각, 자료 상태.
2. 시장: 코스피·코스닥 종가와 전 거래일 대비 등락 및 등락률. 등락률 = `(기준일 종가 / 직전 거래일 종가 - 1) × 100`.
3. 섹터: 기존 섹터 화면에서 사용 가능한 코스피200·코스닥150 섹터별 일간 등락률과 상위·하위 3개. 값이 같은 경우 섹터명 순으로 정렬한다. 섹터의 구성종목 동일가중 평균이라는 정의와 구성종목 가격 결측 여부를 표시한다. 유효/전체 종목 수는 노출하지 않으며 공식 섹터 지수로 표현하지 않는다.
4. 투자자 수급: 이용 가능한 코스피·코스닥 시장별 투자자 순매수액. 원본의 투자자 분류, 단위와 수집 시각을 표시한다. 토스 수급은 KRX·NXT 합산 범위임을 명시하고 KRX 가격과 같은 거래 범위로 오인하게 하지 않는다.
5. 출처·기준·결측: 자료별 원본, 기준일, 수집 시각, 누락 이유와 계산상 유의점.

추가로 코스피200·코스닥150 구성종목의 상승·하락·보합·결측 수와 상승·하락 상위 각 3종목을 표시한다. 시장 전체 집계가 아니며 기준일의 현재 구성으로 계산한다. 일간은 전 거래일, 주간은 해당 주 첫 거래일의 직전 거래일 종가와 비교한다.

### 주간

- 대상은 월요일부터 일요일까지의 KST 달력 주간이다. 주간 보고서는 검증된 거래일 캘린더상 **해당 주 마지막 거래일 15:30 KST 마감 직후**부터 생성한다. 주중 마지막 거래일이 금요일보다 빠른 휴장 주간도 같은 규칙을 쓴다. 특별 운영시간이 확인되지 않으면 생성하지 않는다.
- 보고서에는 달력 주간과 실제 첫·마지막 거래일을 모두 표시한다. 주간 수익률은 **해당 주 마지막 거래일 종가 / 해당 주 첫 거래일의 직전 거래일 종가 − 1**이다. 양쪽 모두 KRX 15:30 종가여야 한다. 해당 주에 거래가 없거나 캘린더를 확인할 수 없으면 생성하지 않고 사유를 표시한다.
- 시장의 주간 수익률 및 일별 추이, 주간 섹터 등락률 상·하위 3개, 거래일별 투자자 수급과 주간 합계를 제공한다. 주간 섹터 수익률은 해당 기간 양 끝의 동일 기준 종목 종가로 계산한 구성종목 수익률의 동일가중 평균이다. 기존 섹터의 1W 값은 달력상 7일 전 기준이므로 이 주간 정의와 일치하는지 검증 전에는 그대로 사용하지 않는다. 현재 구성종목을 과거에 적용하는 한계와 구성종목 가격 결측 여부를 표시한다.
- 수급 합계는 해당 주 모든 거래일 값이 있을 때만 산출한다. 하루라도 빠지면 합계는 결측이며 빠진 날짜를 표시한다. 일별 일부 값은 날짜와 함께 표시할 수 있다.

## 4. 공통 데이터 원칙

- 국내 종목·지수·섹터의 최신 및 비교 가격은 모두 실제 확인된 **KRX 정규장 15:30 KST 종가**를 사용한다. NXT·시간외·거래소 미구분 가격이나 기존 통합 종가 캐시로 대체하지 않는다. 가격이 없으면 결측으로 처리한다.
- 자료별 기준일, 출처, 수집 시각과 거래 범위를 보존한다. 수급·공시 등 가격 이외 자료는 원본의 발표·기준 시각을 유지한다. 지연된 선택 자료를 포함할 때는 실제 날짜를 명시하며 해당 기준일의 값처럼 표시하지 않는다. 기본 제안은 기준일이 다른 수급을 해당 일의 수급으로 사용하지 않는 것이다.
- 현재 프로젝트의 지표·섹터·수급 저장 자료를 재사용하되, 구현 시 각 원본의 필드·거래소·이력·날짜 및 주간 계산 가능 여부를 검증한다. README에 기능이 있다는 사실만으로 준수나 과거 데이터 완전성을 가정하지 않는다.
- 원본별 갱신 일정이 다르므로 특정 시각 이후 일괄 준비되었다고 가정하지 않는다. 수동 생성 시 저장된 자료의 준비 상태를 확인한다. 기준일별 자료가 없는 과거 보고서는 다른 날 자료로 채우지 않는다.
- 결과 스냅샷에는 유형, 선택일/대상 주간, 실제 거래일, 비교 거래일, 각 항목의 값·수집 시각·상태와 생성 시각을 보존한다. 출처·단위·가격 기준은 보고서에 표시한다. PDF 저장 위치는 앱이 관리하지 않는다. 인쇄와 미리보기는 동일 스냅샷을 사용한다.

## 5. PDF 및 저장

- A4 세로 인쇄 레이아웃을 제공하고 표의 제목·단위·기준을 표시한다. PDF 파일명, 글꼴 포함과 페이지 번호는 브라우저 인쇄 설정에 따른다.
- 현재 구현은 보고서 스냅샷을 브라우저 로컬 저장소에 보관하고 PDF는 사용자가 인쇄 대화상자에서 별도 저장한다. 같은 브라우저에서 새로고침·배포 후 이력을 볼 수 있지만 브라우저 데이터 삭제나 기기 변경 시 이력이 사라질 수 있다. 서버 영구 저장소와 접근 제어는 추후 확정한다.
- 1차에서 사용자가 기존 버전을 덮어쓰거나 삭제하는 기능은 제공하지 않는다. 개인용 데이터가 외부에 공개되지 않도록 배포 환경의 접근 범위를 확인한다.

## 6. 상태와 예외

| 상황 | 사용자에게 보이는 동작 |
| --- | --- |
| 장중 또는 휴장일의 일간 선택 | 직전 완료 거래일과 선택일이 다른 이유 표시 |
| 필수 지수 또는 비교 종가 결측 | 해당 항목과 이유 표시, 생성 차단 |
| 선택 자료 결측·수집 실패 | 누락 내용과 실제 상태 표시, 결측 포함 생성 허용 |
| 주간 거래일 또는 캘린더 미확인 | 임의로 거래일을 추정하지 않고 생성 차단 |
| 선택 자료 중 일부 거래일 결측 | 주간 합계·평균을 완전한 값으로 제시하지 않고 결측 날짜 표시 |
| 과거 자료 미보유 | 없는 기간과 항목 표시, 다른 날짜 값으로 대체하지 않음 |
| 브라우저 이력 저장 실패 | 실패 이유와 재시도 제공, 저장 완료로 표시하지 않음 |

## 7. 완료 기준

1. 일간과 마지막 거래일이 마감된 주간을 선택하면 실제 거래일과 비교 기준일이 명확히 표시된다. 휴장 주간과 미확인 캘린더의 동작이 위 규칙을 따른다.
2. 국내 가격과 모든 비교 가격의 KRX 정규장 15:30 기준을 원본 필드까지 검증하고, 다른 세션이나 기존 통합 캐시로 대체하지 않는다.
3. 필수 자료 누락은 생성을 막고, 선택 자료 누락은 화면과 PDF 양쪽에 남는다. 주간 수급의 일부 결측은 합계가 아닌 결측으로 나타난다.
4. 수동 생성 후 미리보기와 PDF의 값·기간·출처·결측 상태가 일치한다. 한글과 표가 A4에서 정상 표시된다.
5. 생성된 스냅샷이 같은 브라우저에서 다시 열리고, 새로 저장해도 이전 스냅샷이 유지된다. PDF 저장은 사용자가 인쇄 대화상자에서 실행한다. 브라우저 저장 실패 시 성공으로 표시하지 않는다.

## 8. 결정이 필요한 사항

- 1차 보고서에 시장·섹터·수급 이외에 꼭 넣을 지표가 있는가? 관심 종목, 공시, 글로벌 프록시는 별도 기준과 자료 준비 상태가 필요하다.
- 주간 보고서는 마지막 거래일 마감 직후부터 만든다. 향후 거래일 캘린더와 예외 휴장 확인이 필요하다.
- PDF 보관 위치와 배포 환경의 사용자 인증 방식을 정한다. 현재 저장소는 개인용 대시보드지만 영구 PDF 저장소가 확보되었다고 가정하지 않는다.
- 자동 생성이 필요하다면 별도 단계로 자료 준비 조건·재시도·실행 환경과 알림 여부를 정한다. 고정된 16시 실행만으로 모든 자료의 준비를 보장할 수 없다.
