# 주요 매크로·실적 캘린더

한국시간 오늘부터 28일간 한국·미국의 주요 일정을 보여준다. 일정의 수집 시각과 출처, 미확정 여부를 표시한다.

## 자동 수집과 운영

`.github/workflows/events-daily.yml`이 매일 07:00 UTC (16:00 KST)에 `npm run events:export`를 실행한다. 기존 국내 데이터 작업과 별도 concurrency 그룹을 사용하며 동시 푸시 충돌은 리베이스 후 재시도한다. 결과는 `data/events/board.json`에 저장해 기본 브랜치 Git 배포로 전달한다.

미국은 무료 [ShowMyTrades 경제 일정 API](https://showmytrades.com/docs/api/economic-calendar)의 USD high 이벤트와 ISM을 가져온다. API 키는 필요 없고 최대 30일을 제공한다. UTC 시각을 KST로 변환하고, 제공처가 `tentative` 또는 `sources_disagree`로 표시한 이벤트는 하단 미확정 영역에 배치한다. 상태가 변경된 이벤트는 표시하고 취소된 이벤트는 새 결과에서 사라진다. 원본은 수집 시점 6시간 전부터 제공하므로 당일 이미 지난 일정은 빠질 수 있다. 사이트 자료가 공식 발표처 확정을 뜻하지는 않는다.

ISM 공식 페이지가 자동 요청에 정상 문서를 반환하지 않아 제조업·서비스업 PMI 일정도 ShowMyTrades에서 수집하며 제공처를 표시한다. 각 출처의 갱신 성공 시각을 기록하고, 원본 응답 구조 오류나 오래된 데이터, 불충분한 기간 또는 네트워크 오류에는 이전 스냅샷을 보존하고 오류를 표시한다. 한 출처가 실패하더라도 다른 성공 결과와 실패 상태를 배포한 뒤 작업을 실패 처리한다.

ShowMyTrades는 KRW를 제공하지 않으므로 한국 매크로는 자동 수집되지 않는다. [Finance Calendar](https://www.financecalendar.com/api/coverage/)는 한국·미국 경제지표를 제공하지만 API는 인증 키가 필요하며 신규 계정 요금 안내가 페이지마다 달라 가입 전 확인이 필요하다. 한국 중앙은행 일정은 해당 목록에 없을 수 있다. 한국 상위 30개 기업의 실적은 아래 DART 수집을 사용하고 미국 기업 실적과 한국은행 매크로는 `lib/events/calendar.ts`의 수동 자료이며, 확인일과 범위 밖에서는 누락될 수 있다. 날짜 미확정 영역의 수동 항목은 예정 사실을 확인한 것만 넣는다.

데이터는 일정의 완전성을 보장하지 않는다. 한국시장 가격은 사용하지 않으며 발표 일시만 KST로 표시한다.


## 한국 실적 발표 일정

DART 키와 KRX 웹 로그인(`DART_API_KEY`, `KRX_ID`, `KRX_PW`)은 GitHub Actions Secrets에 설정해야 한다. 로컬에서는 `.env`를 읽는다. `events-daily.yml`이 매일 한국시간 16시에 각 소스를 수집하고 각 출처의 결과와 오류를 저장한다. 수집 작업은 실패 출처가 있더라도 다른 출처의 정상 결과를 먼저 게시한 후 실패로 표시한다.

코스피(KRX STK) 전 종목을 완료 거래일의 KRX 정규장 15:30 종가 기준으로 조회하고 시가총액=종가×상장주식수를 검증한다. DART 고유번호의 상장 보통주 종목코드에 매핑되는 기업을 시가총액 순으로 정렬해 30개를 고른다. 우선주는 같은 기업을 중복 포함하지 않는다. 기준일·KRX 거래소·15:30 가격 기준과 수집 시각을 별도로 표시한다. 한국시장 휴장·장중에는 직전 완료 거래일을 사용하며, KRX 또는 DART 조회가 실패하면 이전 정상 결과와 마지막 성공 시각을 보존하고 실패를 표시한다. 장 직후 KRX 자료가 늦으면 당일 수집이 실패할 수 있다.

각 기업의 최근 150일 공시 접수를 모든 페이지에서 검색하여 최신 결산실적 공시예고와 여러 기업설명회 공시를 확인해 가장 최근의 실적 관련 설명회를 찾는다. 일반 투자자 행사 공시가 실적 설명회를 가리지 않도록 한다. 원문 ZIP의 크기·CRC를 검증한 뒤 표에 적힌 결산실적 공시예정일을 읽으며, IR은 실적 관련 설명회로 확인된 경우에만 설명회로 별도 표기한다. IR 시각은 실적 공시 시각으로 쓰지 않는다. 정정본은 접수번호 순으로 최신 공시를 사용하고, 정정표의 변경 전후보다 최종 본문을 우선한다. 공시예고는 시간 정보가 불확실하므로 시간 미확정으로 표시한다. 원문 해석 실패는 공시 확인 필요로 표시하며, 공시가 없거나 확인되지 않은 기업을 날짜 미확정 목록에 넣는다. 과거 공시예고를 미래의 날짜처럼 표시하지 않으며, 예정일 이후 실제 실적공시가 확인되면 해당 예고를 종료한다. 이전 분기 설명회와 차기 실적 공시를 혼동하지 않는다.

자동 수집은 DART에 제출되고 읽을 수 있는 공시만 대상으로 한다. 예고하지 않았거나 취소·정정 형식이 다르면 누락 또는 수동 확인이 필요하다. 조회 기간보다 오래된 예고도 누락될 수 있다. 이 목록은 미확정 기업이 향후 4주에 발표한다는 의미가 아니다. 미국 실적과 한국 매크로는 자동 수집 대상이 아니다.
