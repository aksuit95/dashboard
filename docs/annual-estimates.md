# 예상 결산연도 밸류에이션

평일 16시 이후 섹터 KRX 종가 수집이 완료되면 네이버 금융 공개 연간 재무표의 가장 가까운 예상 결산연도 EPS·BPS를 관측한다. 같은 결산연도에 속한 예상치만 사용하며 제공되지 않는 값은 결측이다. 수집 시각은 추정치의 발표시각이 아니라 실제 관측 시각이다. 해당 날짜 KRX 15:30 종가와 결합해 각각 종가/EPS, 종가/BPS를 표시한다. 12개월 선행 컨센서스와는 별도 지표이며 결산연도가 달라지거나 결측이면 선을 끊는다. 추정치 이력은 수집을 시작한 날부터 쌓인다. 요청 실패율이 20%를 넘으면 이전 이력을 보존하고 수집 작업을 실패 처리한다. 종목별 요청 실패와 KRX 종가 부재는 결측이다.
