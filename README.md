# 개인용 한국 주식 리서치 대시보드

한국 정규장 마감 이후에도 해외 프록시(ADR, GDR, 선물, 미국 ETF, DEX 무기한선물)로 한국 주식의 방향을 보고, 수급·공시·대만 매출까지 한 화면에서 확인하는 **개인 연구용** 대시보드입니다.

화면 구성은 [Jusikbot](https://jusikbot.com/)의 공개 페이지를 참고했습니다. 이 저장소는 Jusikbot과 무관하며, 그들의 코드·상표·데이터를 복제하지 않습니다. 시세와 통계는 각자 이용 가능한 공개 출처에서 수집하고, 화면의 숫자 정의는 아래 계산식을 따릅니다.

표시되는 모든 수치는 정보 제공용입니다. 투자 권유나 매매 신호가 아닙니다.

## 이 대시보드가 답하는 질문

- 정규장이 끝난 뒤 삼성전자·SK하이닉스는 해외에서 어떻게 움직이고 있는가.
- ADR·GDR 가격을 보통주 1주 기준으로 환산하면 KRX 대비 프리미엄이 얼마인가.
- 예탁금, 신용잔고, ETF 설정·환매로 수급이 어느 쪽인가.
- 실적 공시와 대만 월매출이 같은 테마를 가리키는가.

## 화면

사이드바는 다섯 묶음입니다. 기본 테마는 다크, 한국어·영어 전환을 둡니다.

| 묶음 | 경로 | 내용 |
| --- | --- | --- |
| Global Proxy | `/` | 한국 주식의 야간 프록시 |
| Market Gauges | `/adr`, `/risk`, `/market`, `/annual-returns` | 등락비율, 위험 지표, 시황·뉴스, 연간 수익률 |
| Fund Flows | `/fund-flow`, `/etf-flow`, `/etf-constituents` | 예탁금·신용, ETF 유출입, 보유 비중 변화 |
| Stocks & Filings | `/movers`, `/dart` | 52주 신고가·급등락, DART |
| AI Trade | `/rel-mcap`, `/taiwan-revenue` | 시가총액 비율, 대만 월매출 |

### Global Proxy (`/`)

정규장 종료 뒤에도 한국 주식의 해외 가격을 카드로 보여 줍니다. 각 카드는 이름, 심볼, 거래소, 장 상태(Live / Closed), 원화 환산 가격, 대비, 등락률을 표시합니다.

- **ADR.** SK하이닉스 나스닥 ADR(`SKHY`). 1 ADS = 보통주 1/10. 화면 가격은 보통주 1주 기준 원화이고, 같은 시각 KRX 종가 대비 프리미엄을 함께 표시합니다.
- **DEX 무기한선물 (Hyperliquid).** `xyz:SMSN`, `xyz:SKHX`, `xyz:SKHY`, `xyz:HYUNDAI`, `xyz:KR200`. 기준은 직전 KRX 정규장 종가 대비 24시간 변화. 8시간 펀딩비는 포지션 쏠림을 읽는 보조 지표입니다. ADR 퍼프는 KRX 퍼프 대비 프리미엄도 표시합니다.
- **글로벌 선물.** KOSPI200 야간선물, Nasdaq 100 선물, S&P 500 선물.
- **매크로.** 미국 10년물 금리, WTI, USD/KRW.
- **GDR.** 삼성전자 런던 GDR(`SMSN.IL`, 1 GDR = 보통주 25주, 1주 환산), SK하이닉스 프랑크푸르트(`HY9H.F`, 1주 환산).
- **미국 ETF 프록시.** Roundhill Memory(`DRAM`), iShares MSCI Korea(`EWY`), iShares Semiconductor(`SOXX`).

프리미엄과 원화 환산은 장중 환율을 씁니다. 환율이 없으면 마지막 유효 환율을 쓰고, 카드에 기준 시각을 남깁니다.

### ADR (`/adr`)

전 시장(코스피·코스닥·코넥스 합산)과 KOSPI·KOSDAQ의 **20거래일** 상승 종목 수 / 하락 종목 수 비율입니다. 전 시장은 한국주식데이터 일별 다이제스트이고, KOSPI·KOSDAQ 과거는 같은 출처의 일별 시세에서 전일대비 부호로 셉니다. 수집일 장중 수는 네이버입니다.

```text
ADR(%) = 최근 20거래일 상승 종목 수 합 / 최근 20거래일 하락 종목 수 합 × 100
```

보합은 분모·분자 어디에도 넣지 않습니다. 경험적 구간으로 120% 이상을 과열, 80% 이하를 과매도로 색만 구분합니다. 차트 구간은 6개월, 1년, 3년, 5년입니다. 당일 스냅샷에는 상승·하락 종목 수와 전일 대비 변화도 표시합니다.

### Risk Indicators (`/risk`)

변동성, 심리, 매크로를 한 화면에 모읍니다.

- **이격도.** `종가 / N일 이동평균 × 100`. N은 25일 또는 50일입니다. 정의가 출처마다 다르므로 화면에 이 식을 고정해 적습니다.
- **변동성.** VIX, SOX.
- **금리.** 미국 장단기 금리차(10년−2년).

KOSPI·KOSDAQ 이격도 차트 구간은 6개월, 1년, 3년입니다.

### Annual Returns (`/annual-returns`)

S&P 500, NASDAQ, KOSPI, KOSDAQ의 연간 수익률 표입니다. **배당은 제외**한 가격 지수 기준입니다. 올해는 연초 대비 현재(YTD)로 표시합니다.

### Fund Flow (`/fund-flow`)

증시 대기 자금과 거래대금을 봅니다.

- 투자자 예탁금
- 신용잔고, 신용잔고/시가총액
- 거래대금 (KOSPI, KOSDAQ, 합산)

금융투자협회(KOFIA) 예탁금·신용잔고는 **2거래일 지연**이 일반적입니다. 그 외 거래대금은 일별입니다. 차트 구간은 6개월, 1년, 3년입니다. 지연 데이터는 기준일을 카드에 적습니다.

### ETF Flows (`/etf-flow`)

가격 등락을 제외한 자금 유출입입니다.

```text
일간 순유출입 ≈ (당일 상장좌수 − 전일 상장좌수) × 당일 NAV
```

미국 ETF(메모리·한국·반도체)와 국내 ETF(섹터, 2배 레버리지, 반도체, 바이오·헬스케어, 소프트웨어, 액티브)를 탭으로 나눕니다. 각 카드에 기준일, 순유출입, 상장좌수, AUM을 표시합니다. NAV가 없는 날은 계산하지 않고 결측으로 둡니다.

### ETF Holdings Change (`/etf-constituents`)

국내 테마 ETF의 구성 종목 비중 변화를 일간·주간으로 봅니다. 비중 스냅샷이 2일치 쌓이기 전에는 "수집 중"으로 표시합니다. 초기 유니버스는 반도체 ETF부터 시작하고, 섹터 탭은 ETF Flows와 같은 분류를 재사용합니다.

### 52주 신고가·급등락 (`/movers`)

KOSPI, KOSDAQ, 미국 시장 탭과 52주 신고가 / 등락률 탭, 일간 / 주간 전환을 둡니다.

제외 규칙:

- 한국 시가총액 1,000억 원 미만, 미국 시가총액 10억 달러 미만
- ETF, ETN, REITs, SPAC

### DART (`/dart`)

시가총액 1,000억 원 초과 종목의 주요 공시만 남깁니다. 카테고리 예시는 잠정 실적, 단일판매·공급계약, 배당, 주주환원입니다. 실적 공시는 매출·영업이익·순이익과, 계산 가능한 경우 PER을 요약합니다. 원문 링크는 DART 접수번호로 연결합니다.

### Relative Market Cap (`/rel-mcap`)

두 기업의 시가총액 비율 추세입니다. 우선주를 포함하는 쌍은 이름을 명시합니다.

초기 쌍:

- SK하이닉스 / (삼성전자 + 삼성전자우)
- SK하이닉스 / 삼성전자
- SK하이닉스 / Micron (달러 시총)
- 삼성전기 / Murata
- 삼성전기 / (Murata + Ibiden)
- 삼성전자 / TSMC
- Broadcom / NVIDIA

차트 구간은 6개월, 1년입니다. 카드에는 현재 비율, 기준일, 분자·분모 시총, 구간 고점·저점을 표시합니다. 통화가 다르면 시총을 달러로 맞춘 뒤 나눕니다.

### Taiwan Revenue (`/taiwan-revenue`)

대만 상장사 월매출입니다. TWSE 공개 데이터에서 당월·전월·전년 동월을 가져오고, 금액은 천 대만달러입니다. 파운드리, 소재, OSAT, PCB, CCL, 광학·CPO, ODM·AI 서버, 설계, 전력으로 묶습니다. 종목 목록은 `config/taiwan.ts`에 있습니다. 섹터 YoY는 전년 동월이 있는 종목의 매출 합입니다.

## 권장 구조

개인용이라 배포 없이 로컬에서 돌아가게 설계합니다. 시세는 서버에서만 가져오고, 브라우저는 자체 API만 호출합니다. 키를 클라이언트에 넣지 않습니다.

```text
app/                  Next.js App Router 페이지
components/           시세 카드, 차트, 표, 사이드바
lib/market/           프리미엄·ADR·이격도·ETF 유출입 순수 함수
lib/sources/          출처별 수집기 (실패 시 빈 값이 아니라 마지막 스냅샷)
jobs/                 장중 폴링, 일별·월별 배치
data/                 SQLite (시세, 일별 지표, 공시, 수집 로그)
config/universe.ts    심볼, ADR/GDR 배수, ETF 목록, 비교 쌍, HS 코드
```

스택은 Next.js, TypeScript, Tailwind CSS, Node 내장 SQLite(`node:sqlite`), Lightweight Charts입니다. Drizzle과 네이티브 SQLite 모듈은 쓰지 않습니다. Node 24에서 추가 빌드 없이 로컬 파일을 열기 위해서입니다. 작업 스케줄은 `npm run job:poll` 또는 Windows 작업 스케줄러로 충분합니다.

## 실행

```text
npm install
copy .env.example .env
npm test
npm run job:ingest
npm run job:backfill
npm run dev
```

Vercel에 올리면 함수 디스크가 읽기 전용이라 SQLite는 `/tmp`에 둡니다. 인스턴스가 새로 뜨면 시세는 비어 있고, 수집 상태 화면에서 다시 받으면 그 인스턴스에만 남습니다. Node.js 24가 필요합니다. `node:sqlite`는 그 버전부터 플래그 없이 동작합니다.

`.env`의 `DART_API_KEY`가 없으면 공시 수집은 실패로 기록되고 기존 공시는 유지됩니다. KOSPI·KOSDAQ 과거 등락 종목 수는 일별 시세의 전일대비로 세고, 수집일 장중 수는 네이버 지수 응답으로 갱신합니다. 전 시장 합산은 일별 다이제스트입니다. 20거래일이 채워진 뒤에만 비율을 계산합니다. 예탁금·신용잔고는 네이버 증시자금 발표일 기준이고, 거래대금은 지수 대금입니다. ETF 좌수·NAV·구성종목은 수집으로 갱신하고, 비중 차이는 스냅샷이 이틀 쌓인 뒤에 계산합니다. 대만 월매출은 TWSE 상장 공개 데이터의 당월·전월·전년 동월입니다. 52주 신고가는 설정의 유니버스만 계산합니다.

수집 주기의 출발점:

| 데이터 | 주기 | 비고 |
| --- | --- | --- |
| Hyperliquid 퍼프, 미국 선물·ETF·환율 | 15–30초 | 장중에만. 휴장에는 마지막 호가 유지 |
| KRX 현재가·종가 | 정규장 1분, 그 외 종가 1회 | 프리미엄의 분모 |
| ADR·이격도·등락률·ETF 유출입 | 장 마감 후 1회, 실패 시 재시도 | 일별 테이블에 적재 |
| 예탁금·신용 | 평일 1회 | 2거래일 지연 표기 |
| DART | 10–15분 | 시총 필터 후 저장 |
| 대만 월매출·상대 시총 | 월 1회 또는 해당 공시일 | 수동 재수집 버튼 |

외부 호출이 실패해도 마지막 성공 시각의 값을 보여 주고, 카드에 `stale`을 표시합니다. 0이나 빈 차트으로 덮어쓰지 않습니다.

## 계산

환율은 USD/KRW 미드(또는 사용하는 피드의 종가) 하나입니다. 모든 원화 환산이 이 값을 공유합니다.

```text
보통주 1주 원화 = 해외 표시가격 × 그 통화의 원화 환율 / 증권 1장이 나타내는 보통주 수
프리미엄(%)   = (비교 가격 / 기준 가격 − 1) × 100
```

`SKHY`는 1 ADS = 보통주 1/10이므로 나눗수는 0.1입니다. 10으로 나누면 1주 가격이 실제보다 100배 작아집니다. 삼성 런던 GDR은 1장 = 보통주 25주입니다. 배수는 `config/universe.ts`에만 두고 화면 코드에 하드코딩하지 않습니다. 법인행동(분할·배수 변경)이 있으면 적용일과 함께 기록합니다.

이격도, ADR, ETF 순유출입 식은 위 화면 절과 같습니다. 순수 함수로 두고 입력 시계열에 대한 단위 테스트를 먼저 작성합니다. 휴장일·결측·거래정지 종목은 분모에 넣지 않습니다.

## 데이터 출처

키와 라이선스는 `.env`와 출처별 약관을 확인한 뒤 연결합니다. 개인 화면 용도로 쓰고, 시세를 제3자에게 재배포하지 않습니다.

| 용도 | 후보 | 주의 |
| --- | --- | --- |
| 미국 시세, 선물, ETF, 환율, 금리 | 사용 중인 시세 벤더 또는 Yahoo Finance 비공식 엔드포인트 | 비공식 엔드포인트는 언제든 막힐 수 있음. 개인 폴링 속도를 낮춤 |
| Hyperliquid 퍼프·펀딩 | Hyperliquid 공개 info API | 심볼은 상장 폐지될 수 있음. 설정에서 끄면 카드가 사라지게 |
| 국내 시세·시총·등락 종목 수 | KRX 정보데이터시스템, 또는 개인이 이미 쓰는 시세 라이브러리 | 이용 범위 확인. 스크래핑 금지 조항이 있으면 사용하지 않음 |
| 공시 | DART Open API | 무료 키. 공정공시 본문 파서는 양식이 자주 바뀌므로 실패 건을 로그로 남김 |
| 예탁금·신용 | KOFIA | 지연 일수를 화면에 고정 표기 |
| 대만 월매출 | TWSE 공개 월매출 | 종목 코드 목록을 설정으로 관리 |

## 구현 순서

한 번에 14개 화면을 만들지 않습니다. 계산이 검증된 화면부터 붙입니다.

1. 앱 셸. 사이드바, 다크 테마, 한국어, 스테일 표시, 면책 문구.
2. Global Proxy. 유니버스 설정, 환율, ADR/GDR 배수, Hyperliquid, 선물·ETF 카드.
3. 일별 배치와 SQLite. 종가, 시총이 쌓여야 이격도·상대 시총·ADR이 그려집니다.
4. ADR, 이격도, 연간 수익률.
5. DART 수집과 시총 필터. 파서 실패는 원문 링크만이라도 남깁니다.
6. 대만 매출·ETF 유출입. 월간·일간 시계열.

각 단계의 완료 기준은 "숫자가 맞다"입니다. 카드가 그려지기 전에 `lib/market` 단위 테스트로 프리미엄, ADR, 이격도, ETF 유출입을 고정합니다.

## 알려진 한계

- 야간 원화 가격은 환율과 배수에 민감합니다. 거래소 표시 통화와 1주 환산가를 카드 부제에 항상 적습니다.
- KOFIA 예탁금·신용은 2거래일 지연입니다.
- 공시 목록만 저장하고 본문은 원문 링크로 엽니다.
- 개인 수집 주기에서는 호가 단위의 실시간 터미널이 되지 않습니다. 방향과 프리미엄을 보는 용도입니다.
